# Selected visual language

Selected territory: Quiet workbench (`territory-a` v1).

## Palette and type
Paper #f6f2e8, blue #243c49, amber #d3902c. Use the system sans-serif stack for UI and a native serif for the title. Test final text/background combinations during implementation.

## Composition and asset treatment
Preserve the original lantern proportions. Scale it responsively without clipping. Leave quiet space around the headline. Put visit information before the workshop story on mobile.

## Interaction and accessibility
Use semantic headings and links, descriptive action text, visible keyboard focus, and text opening hours. Treat decorative repeats of the emblem with empty alt text; keep useful identity information in text.

## Implementation review
Check narrow layouts, zoom, keyboard use, real content length, and contrast. No claim of certification is made by this design record.
