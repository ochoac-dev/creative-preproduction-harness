# Harbor Lantern — fictional original example

Harbor Lantern is an invented neighborhood print-and-repair workshop. Mina Vale, its creative lead, and all feedback/decisions in this example are fictional. Names, copy, Markdown, HTML, and the lantern SVG were authored for this repository; there are no borrowed brand assets, photos, fonts, or third-party artwork. Original files are covered by the repository [MIT license](../../LICENSE), copyright 2026 Carlos Ochoa.

The example asks how a workshop can feel welcoming while making practical visit information easy to find. Two territories explore quiet editorial space and a busier noticeboard; the chosen visual language keeps the calm composition and a clear next action.

Copy this directory into a disposable website project, then follow the [explicit CLI tutorial](../../docs/tutorials/explicit-cli.md) or [guided tutorial](../../docs/tutorials/guided.md). `npm run smoke` does that automatically for both project kinds, recording simulated reviews only in temporary demo roots. No example manifest is preapproved.

`assets/lantern.svg` is cleared for local HTML/SVG and manual use in the demo. Reference URL `https://example.invalid/harbor-lantern/study` is a deliberately non-resolving label for this original local example. Reference registration stores metadata; it does not fetch that URL. No network service is needed.

The HTML composition is an inspectable design study, not a production website or completed accessibility certification. Review keyboard use, contrast, content, responsive layouts, and real device behavior during implementation.
